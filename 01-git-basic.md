What is Git?
Git is a distributed version control system used to track changes in source code, manage versions, create branches, collaborate, and maintain code history.

Git vs GitHub
Git
→ Version control tool
→ Runs locally
→ Tracks code changes

GitHub
→ Remote Git repository hosting platform
→ Collaboration
→ Pull Requests
→ Code Review
→ CI/CD integration
